# That Cat Game

Mobile-friendly Python/Pygame recreation of **That Cat Game**.

## Features

- Touch controls for Android
- Random-direction MOVE mechanic
- Slower movement
- Level selector for Levels 1-10
- Previous / next level controls
- Earlier camera panning
- Original red/blue level endpoints
- Enemy/hand death restarts the current level

## Android / Pydroid 3

1. Download this repository as a ZIP.
2. Extract it.
3. Open Pydroid 3.
4. Install Pygame once:
   ```
   pip install pygame
   ```
5. Open `run_game.py`.
6. Press Run.
7. Landscape orientation is recommended.

`run_game.py` rebuilds the bundled game files automatically and launches the game.

## PC

Install Python and Pygame, then run:

```
python run_game.py
```
